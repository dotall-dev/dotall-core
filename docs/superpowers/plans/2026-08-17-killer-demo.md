# Killer Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build workspace view-search, a live `.all/` HTML visualizer, and a heavy Q3 board pack so a real Cursor+MCP agent can orchestrate xlsx→pptx→docx→pdf while a naive agent drowns in OOXML.

**Architecture:** `dotall-core` walks store cache (never ZIP parts) and builds search/viz JSON. `dotall-cli` and `dotall-mcp` are thin adapters. `dotall viz` is loopback HTTP in the CLI crate only. Pack files are generated by `generate_demos` into `demo/q3-pack/`.

**Tech Stack:** Existing workspace Rust, serde JSON, clap, rmcp. CLI HTTP via `tiny_http`. Browser open via `webbrowser` (skip with `--no-open` in tests).

## Global Constraints

- Spec: `docs/superpowers/specs/2026-08-17-killer-demo-design.md`
- TDD: failing test first, then minimal implementation.
- No `unwrap()` in library code outside tests.
- `cargo fmt` and `cargo clippy -- -D warnings` clean for touched crates.
- Search scans only `cache/views/**` and `cache/model/**` under `.all/objects/`.
- Viz is read-only over `.all/`; never mutate.
- Do not invent wall-clock “minutes saved” in the UI.
- No formula engine; no multi-file apply; no static viz export.
- Surgical OOXML edits already exist — this plan does not add format ops.
- Do not amend commits; do not merge unless asked.

**Interfaces:**
- Consumes: `DotallStore` filesystem under `workspace.all_dir()`
- Produces:
  - `pub struct VizNode { pub name: String, pub path: String, pub bytes: u64, pub children: Vec<VizNode> }`
  - `pub struct VizHistoryEntry { pub path: String, pub version: u64, pub summary: String, pub op_count: usize, pub timestamp: String, pub parent: Option<u64>, pub revert_of: Option<u64> }`
  - `pub struct VizMetrics { pub all_bytes: u64, pub snapshot_part_bytes: u64, pub naive_full_copy_bytes: u64, pub model_cache_hits: u64, pub view_cache_hits: u64, pub estimated_tokens_served: u64, pub estimated_dump_tokens: u64 }`
  - `pub struct VizSnapshot { pub tree: VizNode, pub history: Vec<VizHistoryEntry>, pub metrics: VizMetrics }`
  - `pub fn viz_snapshot(store: &DotallStore) -> Result<VizSnapshot>`

Metric rules (locked):
- `all_bytes`: recursive file size of `.all/` (follow files, skip symlink targets outside `.all/` by skipping symlink dirs/files).
- `snapshot_part_bytes`: sum of unique files under each object’s `state/edits/history/snapshots/parts/` (plus opaque blob files if that is where PDF snapshots live — same directory layout).
- `naive_full_copy_bytes`: for each tracked object, `version_count.max(1) * source_file_len` summed (use 1 if version_count is 0 so a registered file still has a baseline).
- Access log: parse JSONL lines for `model_cache_hit`, `view_cache_hit`, `estimated_tokens` (owned struct; `AccessRecord` is borrow-only Serialize).
- `estimated_dump_tokens`: for each tracked source file, if ZIP then sum uncompressed sizes of entries whose names end in `.xml`, `.rels`, or `.txt`; else file length; tokens = `bytes / 4` (same 4-chars-per-token as `read/budget.rs`).
