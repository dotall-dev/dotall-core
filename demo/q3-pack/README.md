# Q3 board pack — killer demo bake-off

Heavy four-file pack for the Dotall vs no-Dotall bake-off (`docs/superpowers/specs/2026-08-17-killer-demo-design.md`).
Generated by `cargo run -p dotall-cli --example generate_demos` (deterministic).

## The brief (identical both sides)

> Prepare the Q3 board pack. Commission rate is now 15%. Update the workbook,
> then make the deck KPIs, the memo, and the intake form match those figures.
> Do not break formulas, the metrics table, or Word styles.

Success: the four files **agree** on 15% (and on any figures the agent actually
read from the workbook). If the deck still says 10% after Excel says 15%, the
take failed.

This is **orchestration**, not four independent edits: spreadsheet → slides →
memo → routing-slip PDF.

Cached formula results in the `.xlsx` stay stale until Excel opens. That is the
fidelity beat (formulas preserved), not live recalc. The agent must not claim
Commission updated in-file until a human opens Excel or it writes an explicit
value it computed.

## Files

| File | Format | Live target |
|------|--------|-------------|
| `q3-financials.xlsx` | XLSX | Named range `Rate` → `Inputs!$B$2` (currently `0.10`); `Revenue!B5` commission formula `=B4*Inputs!B2` |
| `q3-deck.pptx` | PPTX | Slide 1 shape `KPI` text `Q3 commission 10%` → set to `Q3 commission 15%` |
| `q3-memo.docx` | DOCX | Last body paragraph `Q3 commission rate: 10%.` → `Q3 commission rate: 15%.` |
| `q3-intake.pdf` | PDF | AcroForm field `Rate` (currently `10%`) → `15%`; also `Owner` text field for the routing owner |

## Decoy warning

The pack contains **many** decoy `10%` strings outside the live KPI targets:

- `q3-financials.xlsx`: 12 monthly history sheets (`FY2024-01` … `FY2024-12`),
  each with 80 rows; row 1 note reads `legacy 10% promo`.
- `q3-deck.pptx`: 16 slides; slides 2–16 are appendix slides with `Appendix FY mix 10%`.
- `q3-memo.docx`: 24 prior-year paragraphs `Prior year channel mix stayed at 10%.`

A naive `grep`/unzip will surface dozens of `10%` hits. Use `dotall_search`
(cached views/models only) to find the **live** targets — `Rate` named range,
slide 1 `KPI` shape, the Q3 status line, and the `Rate` AcroForm field — without
touching ZIP XML.

## Dotall agent loop

```text
dotall_init
  → status / inspect each pack file
  → search "10%" / Rate
  → read named Rate + quote cells
  → surgical edits on all four files
  → apply (or flush-on-close)
  → history
  → dotall viz
```

CLI walkthrough (scratch workspace; does not mutate committed binaries):

```bash
chmod +x demo/q3-pack/run-demo.sh
demo/q3-pack/run-demo.sh          # default: $TMPDIR/dotall-q3-demo
./target/debug/dotall viz --port 8765 "$TMPDIR/dotall-q3-demo"
```

Edits use **existing** ops: `set_cell_value` on `Rate`; `replace_shape_text` /
`set_table_cell_text`; `replace_paragraph_text`; `set_form_fields`; plus one
visible run style (bold/color) so native apps look updated.

## Filming steps

1. **Naive Cursor session** — same brief, **no** Dotall MCP, Python + unzip
   allowed. Film the real struggle: unzipping OOXML, grepping XML, breaking
   styles/relationships. Do **not** speed up or edit this footage.
2. **Dotall session** — on a **copy** of the same pack + `dotall init`. Film the
   live MCP loop: `dotall_search` → `dotall_read` → `dotall_edit` →
   `dotall_apply` → `dotall_history`.
3. **Open the four Dotall outputs** in Excel / PowerPoint / Word / Preview to
   show the updated KPIs, memo line, and PDF field.
4. **`dotall viz`** on that workspace — loopback HTTP server, browser tree of
   `.all/` with honest metrics (bytes on disk, snapshot storage saved, cache
   hits, tokens served vs raw dump). For CI / headless runs use
   `dotall viz --no-open` so the server does not try to launch a browser.

If the Dotall agent stalls, **keep the take**. Do not splice CLI into the MCP
session — the bake-off is one live MCP agent, not a hybrid.
